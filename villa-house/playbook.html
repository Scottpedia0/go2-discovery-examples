FULL PIPELINE: Acumatica Configuration

Shipping Rate Tables

Acumatica path: Distribution → Sales Orders → Configuration → Shipping Terms. Add rate rules:

  • Default: 16% of order subtotal
  • Override rules by order type (BW, RZ, WB) if rates differ
  • CPU orders: 0% shipping

Customer Defaults

Acumatica path: Receivables → Customers → [Customer] → Delivery Settings. Pre-configure:

  • Default Ship Via per customer
  • Default warehouse (NC WH)
  • Payment terms (Net 30, Net 60)

Order Type Codes

Acumatica path: Distribution → Sales Orders → Configuration → Order Types. Ensure BW, RZ, WB, SO are all properly configured with default behaviors.

Build time: 1-2 weeks (Acumatica configuration, not custom development).

FULL PIPELINE: Acumatica Generic Inquiry

Consolidated Claim View

Create an Acumatica Generic Inquiry (GI) that joins Case + Sales Order + Shipment + Customer data into a single screen:

// Acumatica Generic Inquiry Definition
// Tables: CRCase (Cases), SOOrder (Sales Orders), SOShipment (Shipments),
//         BAccount (Customers), INItemPlan (Stock Items)
// Join: CRCase.OrderNbr = SOOrder.OrderNbr
//       SOOrder.ShipmentNbr = SOShipment.ShipmentNbr
//       CRCase.CustomerID = BAccount.BAccountID

// Output fields:
// CaseCD, CaseSubject, CustomerName, OrderNbr, InvoiceNbr,
// ShipmentNbr, TrackingNbr, CarrierID, ShipVia,
// ItemDescription, Weight, Dimensions,
// BillingAddress, ShippingAddress

Carrier Portal Auto-Fill

For carriers with web portals (Zenith, TFX, BFX): Browser automation or API integration to pre-fill claim forms with data from the GI. Carrier APIs where available:

  • FedEx Claims API: POST /claim/v1/claims (requires FedEx Developer account)
  • USPS Domestic Claims: https://www.usps.com/help/claims.htm (manual only)
  • Other carriers: Most require manual web form or PDF. The GI-generated data reduces assembly from 5-10 min to under 1 min.

API Reference

Acumatica REST API

  • Base URL: https://acumatica.vandh.com/entity/Default/current/
  • Authentication: OAuth 2.0 or cookie-based login
  • Key Endpoints:
    • SalesOrder -- Create/read/update sales orders
    • Case -- CRM case management (CR306000)
    • Shipment -- Shipment management (SO302000)
    • Customer -- Customer records (AR303000)
    • StockItem -- Inventory lookup (IN202500)
  • Documentation: Acumatica Developer Portal or /entity/Default/current/$metadata

RepZio API

  • Base URL: https://api.repzio.com/v2/
  • Authentication: API key (Bearer token)
  • Key Endpoints: /orders, /customers, /products
  • Order receipts: orderreceipts-new.repzio.com (batch print interface)

BigCommerce API

  • Native Acumatica connector available -- no custom development needed
  • Acumatica Marketplace → BigCommerce Connector
